## 6.11.0 — Редактор задач

Задача поддерживает свободный текст с форматированием, списки, компактный чеклист с Enter и раскрывающиеся разделы. Для Pipeline доступны название, меню блока, копирование этапа и перенос действия. Новые приоритеты создаются в селекторе. Дополнительные свойства можно убрать из задачи или удалить из общего списка с возможностью восстановления. Заметки добавляются по желанию; ранее заполненные заметки сохраняются.

Добавлены дублирование, шаблоны, архив, отдельный срок сдачи и завершение из редактора. Копия получает самостоятельные блоки, вложенные страницы и Pipeline; дата, выполнение и подтверждение дохода сбрасываются. Блоки баз данных продолжают ссылаться на те же источники. Существующие текстовые и чеклистовые блоки открываются в новом редакторе; их идентификаторы сохраняются.

Порядок выпуска: миграция `supabase/migrations/20261103164026_task_editor.sql`, транзакционная проверка `tests/task-editor-database.sql` с rollback, функции `os7` и `os8`, затем frontend. Telegram initData/HMAC и настройки JWT не меняются. Откат: предыдущие версии функций и frontend; новые таблицы и столбец оставить для сохранности данных. После появления rich-text документов старый frontend не использовать для редактирования этих документов.

Проверки: TypeScript/Vite, существующие статические проверки, 52 браузерных сценария, включая сенсорные экраны 320/390/430 px. Нативная клавиатура Telegram WebView требует проверки на физическом телефоне.

# Personal OS 6.3 — Release notes

- Единая запись задачи как источник данных + постоянная страница с блоками и Split Pipeline.
- Backfill существующих `personal_tasks` в связанные страницы без удаления данных.
- Обычные цели: бессрочные, недельные, месячные, произвольная дата, ручной прогресс.
- «Главное» показывает обычные и амбициозные цели, «Цели» управляет обоими типами.
- Фиолетовая шкала важного плана → градиент после сверхплана → анимированная фуксия на 200%.
- Буфер и Страницы объединены в одной вкладке. Финансы, Спорт, Категории скрыты из бокового меню (данные сохранены).
- Split Pipeline вертикальный на телефоне, горизонтальный на больших экранах.
- Восстановлена явная типизация `WorkspaceDatabase.tsx`, устраняющая прежнюю ошибку TS7006.
